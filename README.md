# BMI & Diet Calculator

A Python command-line tool that helps people understand their body mass index (BMI) and daily nutrition needs.

## Problem Statement
Many people don't know whether their weight is healthy or how many calories they should eat each day. This project gives a quick, simple estimate and a sample meal plan.

## Features
- BMI calculation with category (underweight, normal, overweight, obese)
- Daily calorie needs using the Mifflin-St Jeor equation and activity level
- Calorie target for lose / maintain / gain goals, with a safety minimum
- Macro split (protein, carbs, fat)
- Sample vegetarian or non-vegetarian meal plan
- Input validation, and results saved to history.csv

## How to Run
Requires Python 3.8+. No external libraries needed.

    python bmi_diet_calculator.py
